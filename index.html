About Me

한 줄 소개

“정확한 도메인 모델링 + 명확한 API 계약 + 배포/운영까지”를 끝까지 가져가는 백엔드 개발자

기능 구현을 넘어서, 서비스가 실제 환경에서 안정적으로 동작하도록 설계–구현–배포–운영까지 책임지는 개발자를 지향합니다.

강점

  • JWT 인증/인가 흐름 설계 및 Spring Security 기반 보안 설정 경험
  • 도메인 중심 설계로 복잡한 업무 흐름(예약/진료 기록 등)을 구조화
  • API 응답/예외 처리 표준화(일관된 응답 포맷, 예외 핸들링)
  • AWS EC2/RDS 배포 및 운영 이슈 디버깅 경험
  • Swagger 기반 문서화로 프론트엔드 협업/테스트 효율 개선

What I Did

  • 아키텍처 설계: Controller–Service–Repository 계층 분리, DTO 기반 응답 구조 설계
  • 인증/인가: JWT 발급/검증 흐름 설계, Role 기반 접근 제어 구현
  • 도메인 구현: 예약/진료기록 등 핵심 도메인 CRUD + 비즈니스 로직 반영
  • 데이터 설계: ERD 기반 관계 매핑 및 무결성 고려(연관관계/제약 조건)
  • 문서화: Swagger로 API 문서화 및 프론트 협업 지원

Problem → Solution → Result

  • Problem: 의료/예약 흐름처럼 복잡한 업무 프로세스를 서버 모델로 정리해야 했음
  • Solution: 도메인 모델링 + JWT 인증/인가 + API 계약 표준화로 흐름을 구조화
  • Result: 프론트엔드와 정상 연동 가능한 서비스 수준의 API 흐름 구축
  • Troubleshooting: 배포 환경에서 발생한 DB 초기화/SQL 충돌 이슈를 로그 기반으로 분석 후 초기화 전략 개선
